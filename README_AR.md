# غربة | Ghorba Android — مشروع أندرويد أصلي (نسخة تأسيسية)

**ملاحظة مهمة:** هذه حزمة **كود مشروع Android Studio**، وليست ملف APK جاهزًا للتثبيت. لا توجد في بيئة التحضير أدوات Android SDK/Gradle اللازمة لإنتاج أو تجربة APK. لم يتم اختبار تشغيل التطبيق على هاتف فعلي. يحتاج المشروع إلى بناء باستخدام Android Studio أو GitHub Actions قبل تثبيته.

## الوظائف المنفذة في المشروع

- واجهة أصلية لأندرويد باللغة العربية، باسم «غربة» وبداخل الكرة المضيئة شعار ريال مدريد.
- مؤثر حركة للكرة عندما ينطق محرك الصوت، مع ردود نصية بالعامية السورية.
- زر محادثة صوتية: يطلب إذن الميكروفون ثم يجري **جلسة واحدة** من التعرف الصوتي باستخدام خدمة Android SpeechRecognizer؛ عند سماع «ها غربة» في هذه الجلسة يرد. لا يتنصت باستمرار.
- نطق بصوت عربي عبر Android TextToSpeech؛ يحاول اختيار صوت أنثوي عربي إن كان مثبتًا. اللهجة والصوت الطبيعي غير مضمونَين ويعتمدان على هاتفك ومحرك TTS الموجود عليه.
- ذاكرة محلية بقاعدة SQLite؛ **قيم الذكريات وتفاصيل التذكيرات مشفرة AES-256-GCM بمفتاح Android Keystore**. لا توجد مزامنة أو نسخ احتياطي تلقائي.
- تأكيد واضح قبل **حفظ أو حذف** أي معلومة. إمكانية مراجعة الذاكرة وحذف كل عنصر أو جميع المعلومات.
- تذكيرات يحدد المستخدم وقتها ويؤكدها؛ تنبيهات محلية غير دقيقة تمامًا وقد تتأخر مع سياسات توفير الطاقة. بعد إعادة تشغيل الهاتف تُعاد جدولة التذكيرات المستقبلية عند وصول BOOT_COMPLETED إن كانت قاعدة البيانات متاحة.
- اختيار **جهة اتصال واحدة** باستخدام منتقي جهات اتصال أندرويد، وعرض تأكيد قبل حفظ رقمها. لا حاجة لإذن قراءة جميع جهات الاتصال.
- اختيار ملف نصي واحد وحفظ أول 4096 حرف منه بعد عرض معاينة وتأكيد؛ لا توجد قراءة تلقائية للملفات أو الصور أو الرسائل.
- تصدير الذاكرة والتذكيرات في ملف TXT يُختار مكان حفظه صراحةً (الملف المصدر **غير مشفر**؛ احفظه في مكان موثوق).
- اختصار إشعار يظهر «غربة جاهزة» لفتح التطبيق بسرعة، **دون ميكروفون في الخلفية**. قد يمكن للنظام إخفاء الإشعار أو منعه.
- إذا لم يعرف التطبيق إجابة سؤال، يعرض إرسال السؤال إلى البحث في المتصفح **بعد الموافقة**. **ليس بعدُ متصلًا بنموذج AI** للإجابة عن كل الأسئلة.

## الحدود الحالية المهمة

1. **«ها غربة» لا تعمل أثناء قفل الهاتف أو بقاء التطبيق في الخلفية**. لتوفير استماع مخصص دائم تحتاج محرك استيقاظ صوتي محلي موثوق (wake-word engine) متوافقًا مع Android وسياسات خدمات الميكروفون؛ وتحتاج **بصمة صوتية** مدربة على صوت المستخدم لمنع أصوات الآخرين، وهذا غير موجود في النسخة.
2. لا يملك التطبيق سيطرة شاملة على الهاتف. الوصول إلى كل جهات الاتصال والصور والرسائل والكلمات السرية ليس مطبقًا، ولا يُنصح بإتاحته دفعة واحدة. الوصول للبيانات يكون عبر اختيار وفئات أذونات محددة، مع موافقة المستخدم.
3. الصوت الأنثوي السوري شديد الطبيعية يقتضي خدمة صوت متخصصة/أصوات مناسبة، قد تكون مدفوعة؛ اختيار محرك TTS المدمج هنا هو محاولة أولية.
4. لا يمكن ضمان بقاء التطبيق مفتوحًا طوال اليوم؛ يمكن للنظام إيقاف العمليات، خصوصًا مع توفير الطاقة. إشعار الاختصار لا يعني أن التطبيق يسجل أو يستمع.
5. التعرف الصوتي عبر النظام قد يرسل البيانات إلى خوادم مزوّد الصوت وفق إعدادات Android. يطلب التطبيق موافقة صريحة قبل أول جلسة.
6. بيانات الذاكرة على الجهاز فقط، وحذف التطبيق قد يؤدي إلى فقدانها نهائيًا؛ استخدم التصدير عند الحاجة.

## كيف تنتج APK على الكمبيوتر

1. ثبّت **Android Studio** من الموقع الرسمي https://developer.android.com/studio.
2. افتح مجلد `Ghorba_Android` عبر **File → Open**.
3. استخدم Android SDK 35 و JDK 17. إصدار Android Gradle Plugin هو 8.7.3، وإصدار Gradle الملائم 8.9.
4. هذا الأرشيف لا يشمل ملف Gradle Wrapper JAR الرسمي؛ يمكن استخدام Gradle 8.9 المثبّت، أو توليد الغلاف من نسخة Gradle موثوقة عبر `gradle wrapper --gradle-version 8.9`.
5. نفّذ `gradle :app:assembleDebug` أو من Android Studio اختر **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. تجد الملف بعد نجاح البناء في `app/build/outputs/apk/debug/app-debug.apk`.
7. انقل APK إلى هاتف سامسونج، وافتحه واسمح بالتثبيت من المصدر الذي تختاره **فقط إذا كنت تثق بالكود**.
8. اسمح بالإشعارات والميكروفون عندما يطلب التطبيق ذلك. زر الميكروفون يتطلب الضغط اليدوي في كل جلسة.

## خيار البناء السحابي

تتضمن الحزمة ملف `.github/workflows/android-apk.yml` لبناء APK عبر GitHub Actions عند نشر المشروع في مستودع GitHub والتحكم به من حسابك. اختر تشغيل workflow ثم حمّل ناتج `ghorba-debug-apk`. لا يوجد هنا مستودع منشور أو رابط APK جاهز.

## الخصوصية والتأكيد

كل معلومات يتم حفظها أو حذفها أو تصديرها تمر عبر شاشة تأكيد. لا يطلب التطبيق `READ_CONTACTS` أو `READ_SMS` أو وصولًا شاملًا للصور. يتطلب الوصول إلى جهات اتصال/ملفات أن تختار عنصرًا بنفسك. النصوص التي تكتبها لا تُرسل تلقائيًا، مع استثناء أن خدمة التعرف الصوتي الخاصة بنظام التشغيل قد تكون شبكية عند تفعيلها.

## الملفات

- `app/src/main/java/com/ghorba/assistant/MainActivity.java` — الواجهة، الصوت، الأوامر، والتأكيدات.
- `LocalStore.java` — التشفير وقاعدة البيانات.
- `ReminderReceiver.java` و `BootReceiver.java` — التذكيرات.
- `OrbView.java` — الكرة المضيئة المتحركة.
- `app/src/main/assets/ghorba_orb.webp` — صورة الكرة وشعار ريال مدريد.

هذه نسخة تأسيسية تعمل **بعد بنائها وتجربتها بنجاح على هاتف**. هي ليست منتجًا نهائيًا ولا تؤدي بعدُ جميع وظائف المساعد الدائم أو نموذج الذكاء الاصطناعي.

## إضافة الإصدار 1.4 — المحادثة الحرة بالذكاء الاصطناعي

أُضيفت بنية **إجابات حرة غير مبرمجة مسبقًا** تعتمد على خدمة ذكاء اصطناعي خارجية يتم تفعيلها **يدويًا** بعد الموافقة. تحتوي الحزمة على خدمة Cloudflare Worker في `ai-relay/` وشرح مفصل للنشر في `ai-relay/README_AR.md`.

- زر **«✨ فعّلي محادثة حرة بالذكاء الاصطناعي»** لإضافة رابط HTTPS خاص بخدمتك ورمز وصول إليها. رمز الخدمة غير مفتاح OpenAI الأساسي؛ الأول يخزّن مشفّرًا على الهاتف، والثاني يبقى سرًا في الخادم.
- بعد موافقتك، ترسل غربة سؤالك وسياق الحوار القريب إلى الخدمة لتسترجع ردًا بالعربية العامية السورية، وتلفظه عبر محرك النطق على الهاتف إذا كان متاحًا.
- **ذاكرتك لا ترفع تلقائيًا.** يوجد خيار منفصل للسماح بإرسال مقتطفات ملائمة للسؤال من المعلومات التي حفظتها بموافقتك؛ دون هذا الخيار لن تُرسل الذكريات الطويلة المدى.
- في حال عدم اتصال الخادم أو عدم توفر رصيد API تظهر رسالة خطأ، ولا تُلفّق غربة إجابة. الأوامر المحلية والتذكيرات تبقى مستقلة عن اتصال AI.
- لا يستطيع النموذج قراءة تطبيقات الهاتف الخاصة أو تنفيذ أوامر حساسة بمفرده؛ التحكم العملي بقي ضمن قواعد التطبيق وطلب موافقتك.
- تأريخ وتصدير الذكريات يظلان محليين، والحوار الحديث يبقى مؤقتًا حتى توافق على حفظه.

**مهم:** الردود الحرة لن تعمل قبل نشر خدمة `ai-relay` وإعداد مفتاح API ورمز الوصول، وهي قد تكون مدفوعة. **هذا مشروع Android Studio، وليس APK مثبتًا أو خدمة AI منشورة وجاهزة**. لم نتمكن من بناء أو تشغيل APK في هذه البيئة لعدم توفر Android SDK؛ اجتزنا اختبارًا تلقائيًا لخدمة الربط ومراجعة للملفات فقط.

## إضافة الإصدار 1.5 — قاموس المهن مع الصور والفيديو

أُضيف داخل التطبيق زر **«🧰 قاموس المهن • صور توضيحية وفيديو ومصطلحات ألمانية»**:

- **28 مهنة أولية** تشمل الخرسانة، تسليح الحديد، الشدات، البناء، العزل الخارجي، الطينة، المعجون، الدهان، الجبس بورد، البلاط، السكريد، اللامينيت، الأسقف، السقالات، الهدم، النوافذ، الدرج، الكهرباء، السباكة، التدفئة، اللحام، النجارة، السيارات وغيرها. هذا **ليس قاموسًا نهائيًا لكل المهن**، ويمكن توسيعه.
- لكل مهنة: شرح بالعربية، خطوات توجيهية عامة، مواد وأدوات، مصطلحات ألمانية، تنبيهات سلامة، **رسم توضيحي أصلي يعمل دون إنترنت**، ورابط مرجعي، وزران لفتح بحث خارجي عن **صور مواقع حقيقية** و**فيديوهات تعليمية**. الروابط الأخيرة نتائج بحث على الويب، لا قوائم مقاطع تمت مراجعتها فرديًا.
- بحث باسم المهنة أو المصطلح بالعربي أو الألماني؛ يوجد بحث إنترنت لموضوع لم يُضمّن بعد، برغبتك.
- إذا تم **تفعيل خدمة الذكاء الاصطناعي**، يمكن لغربة عند سؤالها عن مهنة معروفة أن تمرر شرحًا تمهيديًا ذا صلة إلى خدمة AI لتناقشك بحرية مع إبراز المخاطر. النص المهني غير شخصي؛ **الذكريات الشخصية لا تُرسل إلا حسب خيار موافقتك المنفصل**.
- لا توجد أسعار لحظية، أو معايير هندسية مضمونة الحداثة، أو مشاهدة وتحليل تلقائي للفيديوهات، أو استيراد شامل لجميع المهن. المواصفات الفنية ونشرات الشركات وتصميم المهندس هي المرجع عند التنفيذ.

## إصدار التحضير للبناء 1.6 — تقرير حالة صريح

أُضيف سير عمل GitHub Actions لبناء APK تجريبي موقّع تلقائيًا وتصدير SHA-256، وفحص `release_check.py` للخصوصية والملفات ومتطلبات البناء. التعليمات العربية في `BUILD_APK_AR.md`.

**ما يزال ملف APK غير موجود في هذه الحزمة.** يجب تشغيل البناء على بيئة تتضمن Android SDK وGradle، ثم اختباره على هاتف سامسونج. خدمة AI غير منشورة، والاستماع الدائم ليس مضمونًا، ولا تتوفر بصمة صوتية للمستخدم أو صوت سوري أنثوي مخصص. كل ذلك مذكور حتى لا يُعتبر المشروع منتجًا مكتملًا قبل التحقق الفعلي.
