# خدمة الإجابات الحرة — غربة

البرنامج يستعمل خدمة Cloudflare Worker وسيطة على عنوان HTTPS خاص بك؛ **مفتاح OpenAI API يبقى في أسرار الخادم، وليس داخل تطبيق أندرويد.** يتطلب حساب Cloudflare وحساب OpenAI API مع رصيد متاح. قد توجد تكلفة استخدام مستقلة عن اشتراك ChatGPT.

## النشر

1. افتح Terminal على الكمبيوتر داخل مجلد `ai-relay` وثبّت Node.js إذا لم يكن موجودًا.
2. شغّل `npx wrangler login` للدخول إلى Cloudflare.
3. شغّل `npx wrangler secret put OPENAI_API_KEY` وأدخل مفتاح API من حسابك في OpenAI. **لا تشاركه مع أي شخص ولا ترسله في المحادثة.**
4. أنشئ رمز وصول طويلًا عشوائيًا خاصًا بغربة ثم شغّل `npx wrangler secret put GHORBA_CLIENT_TOKEN` وأدخله عند الطلب؛ احفظ هذا الرمز بسرية. مختلف تمامًا عن مفتاح OpenAI.
5. شغّل `npx wrangler deploy` وستحصل على عنوان مثل `https://ghorba-private-ai.USER.workers.dev`.
6. افتح **غربة → ✨ فعّلي محادثة حرة** على هاتفك؛ ضع رابطًا ينتهي بـ **`/chat`** مثل `https://ghorba-private-ai.USER.workers.dev/chat`، وضع **رمز الوصول الخاص بغربة** (وليس مفتاح OpenAI)، واختر إن كنت تسمح بإرسال مقتطفات ذكرياتك المحفوظة مع الأسئلة ثم وافق.
7. اكتب أو قل أي سؤال جديد؛ عندما يعمل الاتصال ستستعمل غربة خدمة الذكاء الاصطناعي لإجابة غير مبرمجة مسبقًا.

## الخصوصية

- لا يوجد نشر تلقائي لذكرياتك؛ التفعيل يقتضي موافقة صريحة داخل التطبيق.
- عند التفعيل تُرسل **رسالتك والحوار الحديث في الذاكرة المؤقتة** إلى Worker الخاص بك. عند تفعيل اختيار الذكريات تُرسل كذلك **مقتطفات محدودة ملائمة للسؤال** وليست كل الذاكرة أو الهاتف. إيقافه يتم من زر إعداد الإجابات الحرة.
- يحتفظ الهاتف بالذكريات محليًا مشفّرة؛ خدمة Worker هنا ليست قاعدة بيانات ذكريات. يسري على الخدمة ومزوّد النموذج شروط الخصوصية الخاصة بهما. يستخدم الطلب `store:false` حتى لا تحتفظ Responses API بحالة الاستجابة افتراضيًا؛ هذا لا يعني عدم معالجة الطلب أو انعدام سجلات السلامة أو الشبكة.
- لا تضَع سر OpenAI في ملفات التطبيق أو GitHub أو رسالة دردشة. **أي شخص يمتلك رمز الوصول إلى Worker يستطيع استهلاك رصيد النموذج**؛ احفظه بسرية وجددّه إذا تسرب.
- التشغيل الحالي **نصوص + محرك نطق في الهاتف**. لا يوجد ضمان لصوت سورية أنثوي طبيعي، ولا تعرف بصمة الصوت الخاصة بك، ولا اتصال ذكاء اصطناعي للاستماع في الخلفية.

## ملاحظات

- ملف APK ليس ضمن الحزمة، ويحتاج البناء باستخدام Android Studio أو GitHub Actions.
- الملفات لا تنفّذ أوامر حساسة بناءً على رد النموذج؛ فتح التطبيقات والإجراءات الأخرى ما زالت تخضع لقواعد التطبيق وموافقاته.
- تحتاج إنترنتًا أثناء المحادثات الحرة، وقد توجد تكلفة لكل طلب. ويمكنك إيقاف الميزة والعودة إلى الردود المحلية.
